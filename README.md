# Sothis
Mod for Slay the Spire II that adds Sothis as a playable character.

Sothis is an existing character from the Astrea, a game similar to Slay the Spire.
This mod aims to incorporate the dice, statuses, and blessings of Sothis into cards, powers, and relics.

Note: This mod does not aim to recreate Sothis 1:1.
Gameplay adjustments and jugdment calls have been made to make Sothis play like a Slay the Spire character, while still retaining the strategies and builds from Astrea.
